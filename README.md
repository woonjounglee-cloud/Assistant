# Assistant

업무 보조 도구를 제공하는 웹 애플리케이션입니다.

## 기능

### 💰 OT 수당 계산기

- **기본 OT 계산**: OT 시간만을 고려한 수당 계산
- **추가 OT 계산**: 기본 OT + 추가 OT 시간을 모두 포함한 수당 계산
- **세전/세후 수당**: 세전 수당과 세금 공제 후 실제 입금액 표시
- **D-Day 사용**: 체크하면 총 OT 시간에서 8시간을 차감하여 계산
- **총 OT 시간 표시**: 하트 아이콘으로 근무 강도 시각화
  - ≤26시간: ❤️ (1개)
  - 27~38시간: ❤️❤️ (2개)
  - >38시간: ❤️❤️❤️ (3개)

#### 계산 공식

```
세전수당 = (OT 시간 - 14) × 30,796 × 1.5
총 입금(세후) = 세전수당 × (1 - 0.24 × 0.8) = 세전수당 × 0.808
```

- 시급: 30,796원
- 세금 공제: 24%의 80% = 19.2%

### ⛳ SSGG - 골프 티밍 구성

골프 정모를 위한 팀 구성 프로그램입니다.

- **멤버 관리**: 닉네임, 이름, 월별 타수 관리
- **타수 입력**: 3월~10월까지 월별 타수 입력
- **평균 계산**: 입력된 타수의 평균 자동 계산
- **정모 참여**: 참여 여부 체크박스
- **티밍 알고리즘**: 4명씩 팀 구성, 각 팀의 평균 타수가 최대한 비슷하게 배치
- **데이터 저장**: 브라우저 localStorage에 자동 저장

## 사용 방법

1. 브라우저에서 `index.html` 파일을 엽니다
2. 상단 탭에서 원하는 기능을 선택합니다
   - **💰 OT 수당 계산기**: OT 수당 계산
   - **⛳ SSGG**: 골프 티밍 구성

### OT 수당 계산기 사용법

1. "OT 시간" 필드에 기본 OT 시간을 입력
2. "추가 OT 시간" 필드에 추가 OT 시간을 입력 (선택사항)
3. "D-Day 사용" 체크박스를 선택하면 계산시 8시간이 차감됩니다
4. 실시간으로 계산 결과 확인

### SSGG 사용법

1. **타수 입력**: 각 멤버의 3월~10월 타수를 입력합니다
2. **정모 참여 체크**: 이번 정모에 참여하는 멤버의 "정모참여" 체크박스를 선택합니다
3. **저장**: "💾 저장" 버튼을 클릭하여 데이터를 저장합니다
4. **티밍 짜기**: "🎯 티밍 짜기" 버튼을 클릭하면 참여자를 4명씩 균형있게 팀으로 나눕니다
5. **새 멤버 추가**: 하단 폼에서 닉네임, 이름, 기본 타수를 입력하고 "추가" 버튼을 클릭합니다
