# Assistant

OT 수당 계산 및 D-Day 계산기를 제공하는 웹 애플리케이션입니다.

## 기능

### 💰 OT 수당 계산기

- **기본 OT 계산**: OT 시간만을 고려한 수당 계산
- **추가 OT 계산**: 기본 OT + 추가 OT 시간을 모두 포함한 수당 계산
- **세전/세후 수당**: 세전 수당과 24% 세금 공제 후 실제 입금액 표시
- **총 OT 시간 표시**: 하트 아이콘으로 근무 강도 시각화
  - ≤26시간: ❤️ (1개)
  - 27~38시간: ❤️❤️ (2개)
  - >38시간: ❤️❤️❤️ (3개)

#### 계산 공식

```
세전수당 = (OT 시간 - 14) × 25,000 × 1.5
총 입금(세후) = 세전수당 × 0.76 (24% 세금 공제)
```

### 📅 D-Day 계산기

- **날짜 선택**: 목표 날짜를 선택하여 D-Day 계산
- **실시간 표시**: 남은 일수를 D-Day 형식으로 표시
  - 미래: D-[숫자]
  - 당일: D-Day
  - 과거: D+[숫자]

## 사용 방법

1. 브라우저에서 `index.html` 파일을 엽니다
2. **OT 수당 계산**:
   - "OT 시간" 필드에 기본 OT 시간을 입력
   - "추가 OT 시간" 필드에 추가 OT 시간을 입력 (선택사항)
   - 실시간으로 계산 결과 확인
3. **D-Day 계산** (선택사항):
   - "D-Day 날짜 계산하기" 체크박스 선택
   - 목표 날짜 입력
   - D-Day 결과 확인
